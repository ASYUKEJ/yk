# yk — страница стримера Yumika Karimey

Статичный сайт: профиль, компьютер, топ донатеров, Meme Alerts, бустеры, ссылки и статусы рекомендуемых Twitch-каналов.

## Файлы

- `index.html` — разметка страницы
- `symbols.css` — стили
- `app.js` — логика: Twitch-статусы, донаты, автообновление, аккордеон
- `img/yk.jpg` — аватар
- `data/donations.json` — локальный источник донатов (резервный, без токенов)

## Запуск

Открывать лучше не через `file://`, а через локальный сервер — иначе браузер блокирует `fetch` локального JSON:

```bash
python -m http.server 8000
```

Затем откройте <http://localhost:8000>.

## Донаты

Кнопка **«Обновить»** в шапке запускает ручное обновление. Время последнего обновления и текущий источник данных скрыты от посетителей (элемент `#sync-status` с атрибутом `hidden`); при необходимости их можно показать, убрав `hidden` в `index.html`.

Источники опрашиваются по порядку из `CONFIG.DONATION_PROVIDERS`:

1. `donationalerts` — нужен `DONATIONALERTS_TOKEN`; данные берутся из истории донатов, которая питает ленту <https://www.donationalerts.com/dashboard/activity-feed/donations/>
2. `streamelements` — нужен `STREAMELEMENTS_TOKEN` (JWT) и желательно `STREAMELEMENTS_CHANNEL_ID`
3. `streamlabs` — нужен `STREAMLABS_TOKEN`
4. `json` — `data/donations.json`, работает всегда и без токенов

Источник без токена пропускается. Если API недоступен, используется кэш из `localStorage` (24 часа), затем демо-данные.

### DonationAlerts и топ донатеров

Топ-5 считается суммой донатов по каждому имени за те страницы истории, которые запрошены (`CONFIG.DONATIONALERTS_PAGES`, по умолчанию 2). У DonationAlerts нет публичного эндпоинта «топ за всё время», поэтому для точного топа увеличьте число страниц или обновляйте `data/donations.json` вручную.

Автообновление топ-донатеров происходит каждые 30 секунд (`CONFIG.REFRESH_INTERVAL`) и вручную — кнопкой **«Обновить»**. Суммы в рублях отображаются символом `₽`.

### Как задать токены

Вариант 1 — вписать в `CONFIG` в начале `app.js`.

Вариант 2 — один раз выполнить в консоли браузера (токены сохранятся в `localStorage`):

```js
YumikaSystem.setTokens({ donationalerts: 'ВАШ_ТОКЕН' });
YumikaSystem.setTokens({
  streamelements: 'JWT_ИЗ_ПАНЕЛИ',
  streamelementsChannelId: '24символьныйID'
});
YumikaSystem.refresh();
```

Очистить сохранённый токен: `YumikaSystem.setTokens({ donationalerts: '' })`.

Порядок источников можно поменять на лету:

```js
YumikaSystem.setProviderOrder(['streamelements', 'json']);
```

### Режимы данных

`CONFIG.USE_MOCK_DATA`:

- `'auto'` (по умолчанию) — реальные источники, при неудаче локальный JSON или демо
- `true` — всегда демо-данные
- `false` — только реальные источники, без демо-заглушки

Переключение из консоли: `YumikaSystem.setMockMode(true | false | 'auto')`.

### Формат `data/donations.json`

```json
{
  "donators": [
    { "name": "Naokifuri", "amount": 1770, "currency": "RUB" },
    { "name": "Леми", "amount": 536.74, "currency": "RUB" }
  ]
}
```

Можно писать сумму строкой (`"1770 ₽"`, `"536,74 ₽"`, `"$5"`) — число и валюта распознаются автоматически. Рубли в интерфейсе показываются символом `₽`. Топ-5 считается суммой донатов по каждому имени.

## Важно про безопасность

Сайт статический, поэтому любые токены в `app.js` или `localStorage` видны всем посетителям. Для публичного размещения не храните там секретные токены — используйте собственный бэкенд/прокси, который держит токен на сервере.

Некоторые API (DonationAlerts, StreamLabs) могут не разрешать прямые запросы из браузера (CORS). В этом случае нужен прокси или локальный JSON.
